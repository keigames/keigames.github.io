# keigames.github.io

The Kei Games website: https://keigames.github.io

- `/` the studio home page
- `/godling/` the Godling page
- `/godling/privacy/` Godling's privacy policy (linked from the store listings)
- `/godling/get/` one link for every phone: Android goes to Google Play, iPhone to the App Store, once each is
  out. Flip `live` in its `STORES` list when a store launches.

Plain HTML and CSS, no build step and nothing loaded from other sites. The art is rendered by the game itself
(`tools/make_store_art.gd` in the Godling repo). Silkscreen font: SIL Open Font License (`assets/fonts/OFL-Silkscreen.txt`).
